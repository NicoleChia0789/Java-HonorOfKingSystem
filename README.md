# Honor of Kings Social Network System

## Project Overview

The Honor of Kings Social Network System is a Java-based application developed as a team assignment. The project demonstrates the implementation of graph-related operations and character management functionalities in a social network system.

The system uses graph concepts to represent and manage relationships between characters.

## Technologies Used

- **Programming Language:** Java
- **IDE:** Apache NetBeans
- **Build Tool:** Apache Maven

## Key Features

- Character Management
- Add and Remove Characters
- Search and List Characters
- Character Lookup
- Graph Operations
- Relationship Management

## How to Run

1. Download or clone this repository.
2. Open Apache NetBeans.
3. Select **File → Open Project**.
4. Locate and open the downloaded project folder.
5. Allow Maven to load the required dependencies.
6. Locate `Main.java` and run the application if it contains the main entry point.
